# 📚 Course Registration – HTML Project

A simple **Course Registration website** created using **HTML only** as part of my learning and practice in HTML.

This project helped me understand the basic structure of a web page and how different HTML elements can be used to create a simple website and registration form.

## 🚀 About the Project

The **Course Registration** project is a basic static website that provides information about software technology training and includes a course registration form.

This project was developed **using only HTML**, without using CSS, JavaScript, or any external frameworks.

## ✨ Features

* 📖 Simple Course Registration webpage
* 📝 Registration form
* 🏷️ Training and technology-related information
* 🔗 Basic HTML page structure
* 📋 Tables and form elements
* 🎯 Beginner-friendly static website

## 🛠️ Technologies Used

* **HTML5**

> This project was intentionally created using only HTML to practice and strengthen my fundamental HTML concepts.
